# 一般部門 RAG 知識庫問答

本功能提供 ADMIN `/knowledge-qa`，讓一般同仁使用目前部門已配置的知識庫提問；不取代既有資訊部 `/knowledge/chat` 測試頁或 RAG 管理流程。

- 功能目錄 `rag_qa` 的查看權對應 `rag.qa`；登入或擁有管理權不自動取得問答權。
- 每題使用既有 RAG 服務重新依目前部門檢索。來源必須 can_read、use_for_qa、核准、啟用且有檔案；不讓瀏覽器選擇或夾帶知識庫清單。
- 單欄對話、引用及清除對話；無來源時停用送出。對話不建立新的永久儲存。
- POST 驗同源，切換部門後的舊頁面拒絕並要求重整。既有部門 SQL 與 RAG 回答邏輯保留，不另建立一套檢索服務。
- 未新增資料表、環境變數或模型供應商設定。來源與部門設定仍由既有管理功能維護。

離線測試涵蓋登入、逐操作授權、撤銷後重查、跨部門舊頁面、來源限制、HTML 跳脫與既有檢索路徑。合成瀏覽器流程已驗；真實資料庫搜尋與部署 Preview 尚待驗收。不得把合成回答當成模型實測品質。
