# Show Case 管理與參考

本功能讓維護人員從正式供應商新增範例、逐欄核對與啟停，讓已登入使用者查閱有效範例，沒有自動採納到正式發票的行為。跨站交付順序與未驗收項目見 FEATURE-DELIVERY-20261106.md。

- 新增入口必須綁定正式供應商 UUID；供應商名稱與統編由主檔讀取。舊私有範例可查閱及修訂，但不改掛另一家主檔，也不再新增私有供應商。
- 功能目錄 show_case 對應維護查看／新增／修改；supplier.showcase-activation 的修改代表人工確認啟用、退回及停用。與目前部門授權逐次檢查，不因職稱或登入自動開放。
- JPG／PNG 上限 4 MB、二千萬像素，驗完整解碼。上傳先保留 reservation，失敗可追查，不自動刪原圖。
- 原文、空白、不可讀、不適用及待確認分開；修訂保留歷史，啟用不沿用舊版確認。正式目前版與歷程版本／狀態／原圖不一致時拒絕更新。
- 表頭、明細、歷程與事件同交易；事件不可覆寫。沒有實體刪除，也不對既有 invoices 寫入測試結果。
- 瀏覽器與 API 只提供符合條件的啟用範例；每次讀圖重驗來源版本與摘要。前台經 API，不取得 DB 或 Storage Key。
- Gemini 基線與 Few-Shot 比較保存候選及出處；人工確認仍由操作者完成。實測比較只有 7 個共同關鍵欄位，不能將未支援的明細混為同一正確率。

本次沒有執行正式 migration、資料搬移或雲端儲存／模型驗收。正式啟用前需 DB 負責人確認結構與最小權限，團隊完成 Preview 驗收後再決定發布。
